# Smart Restaurant Ordering & Customization System

## 📋 Overview

A full-stack web application enabling customers to browse menus, customize food items, place orders, and track real-time status. Staff and admin manage menu items, handle orders, and view analytics.

## 🎯 Core Features

### Customer Features
- 🍽️ Digital menu with categories, images, and pricing
- 🛒 Advanced food customization (add-ons, removals, special notes)
- 📦 Order type selection (Dine-In, Takeaway)
- 📍 Real-time order tracking (Placed → Accepted → Preparing → Ready → Delivered)
- 👤 User authentication & profile management
- 🧾 Order history & invoice generation

### Staff/Admin Features
- 📊 Admin dashboard with sales analytics
- 🍳 Kitchen display system (KDS) with real-time updates
- 📋 Order management & status updates
- 📈 Performance metrics & peak hour analysis
- 🔐 Role-based access control

## 🚀 Advanced Features

- 🔔 Real-time WebSocket updates (Socket.IO)
- 💳 Payment integration (Cash/Online)
- 🌐 Multi-language support (English, Sinhala, Tamil)
- ⭐ Reviews & ratings system
- 📱 QR code table menus
- 📱 PWA for offline support
- 🎨 Dark mode support
